# Handoff

Проект начат 2026-09-26 как браузерная игра на одного для usertrv.dev (портфолио). Отвечай по-русски.
Дизайн: `docs/design.md`. Репозиторий `userTrv/demolition`, работа только через PR в `main`.

## Как пришли к идее

Кирилл хотел игру на одного по мотивам Just Jump и Boat Move. Пульт с телефона отвергнут: нужна чисто браузерная
игра на одном устройстве. Рыбалка отвергнута: такая игра уже есть. Из второй пачки идей выбран **Подрывник**.
Отклонённые варианты: регулировщик, гравиманёвр, дрон-курьер, песочница с песком, машина Голдберга, парковщик.

## Что есть

Играется от меню до итога: три уровня (гараж, пятиэтажка, башня), заряды с задержками, обратный отсчёт,
обрушение по физике, пыль и обломки, звёзды, прогресс в `localStorage['demolition-progress']`.

- `public/game/building.js` — каркас из блоков: колонны, плиты, стены, опоры (`supports`/`need`) и связи (`links`).
- `public/game/sim.js` — физика на Rapier, без three.js (тесты гоняют её под Node):
  - целое здание — неподвижные тела; после подрыва модель опор отпускает неподдержанные блоки волной;
  - связанные блоки волны — одно составное тело (несколько коллайдеров на одном теле);
  - кусок раскалывается от удара (торможение > 5 м/с за шаг; сминается только нижний пояс в этаж)
    и ломается на блоки на крене 30–50°; стены хрупкие; колонну сминает только удар, не нагрузка.
  - Отвергнуто: фиксированные джоинты между блоками. Длинные цепочки вязли (башня зависала на шарнире)
    и при 4 итерациях решателя выстреливали блоками.
- `public/game/score.js` — доля массы в зоне (разрушенный блок считается там, где рассыпался), устоявшее,
  задетые соседи, звёзды.
- `public/game/levels.js` — уровни; у каждого есть решение в пределах лимита зарядов, проверенное тестом.
- `public/render/*` — сцена three.js, процедурные текстуры, эффекты (обломки без физики, пыль, вспышки).
- `public/main.js` — оболочка и цикл; `window.demolition = { game, view }` для отладки из консоли.
- `public/vendor/` — three.js и Rapier, копируются из `node_modules` командой `pnpm vendor`.

## Сайт

Игра собирается сайтом `presentation-site` при деплое (`pnpm install --frozen-lockfile && pnpm build`,
`dist/` → `/projects/demolition/`). Обложка карточки: `presentation-site/public/img/projects/demolition.webp`,
снята headless Chrome через CDP (уровень «Башня», решение из тестов).

## Следующие шаги

1. Поиграть живьём: темп обрушения, читаемость зарядов на телефоне, сложность уровней.
2. Повтор обрушения с другой камеры, замедление.
3. Больше уровней: мост, дымовая труба, здание со стеклянным соседом; типы зарядов и бюджет.
4. Музыка и звуки богаче (сейчас синтез WebAudio).

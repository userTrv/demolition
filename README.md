# Demolition

Браузерная игра на одного: расставь заряды, подорви здание и уложи его в зону сноса, не задев соседей.
Физика Rapier, графика three.js, без сборки и сервера.

Дизайн: [`docs/design.md`](docs/design.md). Контекст и следующие шаги: `HANDOFF.md`.

## Запуск

```bash
npm run dev          # http://localhost:3000
npm test
```

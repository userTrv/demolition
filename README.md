# Demolition

Браузерная игра на одного: расставь заряды на колонны, задай задержки, подорви здание и уложи его в зону сноса,
не задев соседей. Физика Rapier (WASM), графика three.js, без бандлера и сервера.

Играть: https://usertrv.dev/projects/demolition/

Дизайн: [`docs/design.md`](docs/design.md). Устройство и следующие шаги: [`HANDOFF.md`](HANDOFF.md).

## Запуск

```bash
pnpm install
pnpm dev             # http://localhost:3000
pnpm test            # физика сноса и уровни под Node
pnpm build           # dist/ для сайта
pnpm vendor          # после обновления three или Rapier: скопировать их в public/vendor/
```

## Управление

- Мышь: ЛКМ по колонне ставит заряд, повторный клик по выбранному заряду снимает его; правая кнопка
  и колесо двигают камеру; 1–4 выбирают задержку, пробел взрывает, Esc возвращает к уровням.
- Телефон: тап по колонне ставит заряд, двумя пальцами двигается камера.

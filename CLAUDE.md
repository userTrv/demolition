# Demolition

Контекст проекта и следующие шаги: `HANDOFF.md`. Дизайн: `docs/design.md`. Запуск: `README.md`.

- Проверка: `npm test`; вживую: `npm run dev` и открыть http://localhost:3000.
- Без сборки и фреймворков, ES-модули в `public/`, только относительные пути (игра будет жить под префиксом
  `/projects/demolition/`).
- Тексты интерфейса и комментарии по-русски.
- На сервере (VDS с VPN) ничего не делать без явного разрешения Кирилла.

## Зависимости

- Ставить только версии, опубликованные не меньше 7 дней назад. npm это проверяет сам (`min-release-age` в `.npmrc`), для остального (бинарники, файлы в `public/vendor/`) смотреть дату релиза вручную.
- Только известные пакеты из официального реестра: с историей, живым репозиторием и заметным числом скачиваний. Перед добавлением нового пакета проверять точное имя (тайпсквоттинг), автора и нужен ли он вообще. Без git- и URL-зависимостей.
- Версии в `package.json` точные, без `^`/`~`; `package-lock.json` коммитить вместе с `package.json`, ставить через `npm ci`.
- Библиотеки для браузера (three.js, Rapier) — копией из `node_modules` в `public/vendor/`, а не с CDN. Если всё же CDN в import map — только точная версия и `integrity`.
- Настройки защиты в `.npmrc` не ослаблять и не обходить (`--min-release-age=0`, `--allow-git`, `--ignore-scripts=false` и т. п.) без явного согласия владельца. Скрипты установки разрешены только пакетам из `allowScripts` в `package.json`; добавлять туда пакет — только после того, как посмотрел, что делает его скрипт.
- Нужен npm 11.19.1 или новее (`packageManager` и `devEngines` в `package.json`).

## Секреты и доступы

- Никаких ключей, токенов и паролей в коде, коммитах, логах и комментариях. Доступы к серверу в репозиторий не попадают.
- `.env*`, `*.pem`, `*.key`, `certs/` в `.gitignore`; перед коммитом смотреть `git diff --cached` на предмет случайно попавших секретов.
- Не выводить секреты в консоль (`echo`, `set -x`, `env`, `cat` ключа), не передавать их аргументами командной строки, не отправлять во внешние сервисы.
- Нашёлся утёкший секрет — сразу сообщить владельцу: его надо отозвать и перевыпустить, одного удаления из истории мало.
